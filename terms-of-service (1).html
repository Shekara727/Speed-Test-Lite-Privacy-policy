Section 02

Description of Service

Speed Test Lite is a free network utility designed to measure internet connection performance—including Ping (RTT), DNS Server Round-Trip Time (RTT in milliseconds), Jitter, Download speed (Mbps), Upload speed (Mbps), estimated 1 GB file download duration, and local network diagnostics (Wi-Fi, 4G/5G status, local IPv4, and gateway details).

  • Informational Measurements: Speed test and latency results reflect real-time network conditions at the moment of testing and may vary based on router load, carrier congestion, signal strength, and device hardware.
  • Data Usage Notice: Running Download and Upload speed tests transfers test data over your active Wi-Fi or mobile data connection. Standard carrier data charges may apply if you run tests on a metered mobile network.
